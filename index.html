How this works. Discord forbids automating a user account, and no bot API can invoke another bot's commands. So these buttons copy the exact command to your clipboard — you paste and send it yourself. Same few keystrokes saved, no risk to your account. Behind one interface, so a real sender drops in if Dundor ever ships an API.
